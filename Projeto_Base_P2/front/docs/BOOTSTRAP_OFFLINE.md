# Bootstrap local

O projeto contém os arquivos locais do Bootstrap 5.3.3 na pasta:

```text
front/vendor/bootstrap/
```

O `index.html` já está configurado para utilizar os arquivos locais.

Durante a prova, não será necessário acessar uma CDN ou instalar o Bootstrap pela internet.

O estudante deverá consultar os arquivos e os componentes disponíveis no próprio projeto, conforme a orientação do professor.
